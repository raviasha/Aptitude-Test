# Preserved development sources

`android-extension-76953dd.zip` contains the complete tracked tree of the former
`codex/android-extension` branch at commit
`76953dd4bf4707642953dbc42bccf032d47d88db`, including its three Android commits.

SHA-256: `7493188f229fa9491ad374314321921c4e4b3c6a88b74cf4eea01233834d5f42`.

Extract into a separate folder to inspect or continue the Android project. Its
`ANDROID_APK_BUILD.md` documents the original build. The branch predates the
distributed coordinator and depends on its own older application and frontend;
its shared application files have not replaced the current coordinator. This
snapshot preserves the work on main without claiming compatibility with the
current application or a newly verified Android build.
