# Standalone question banks

Files in this folder are published separately on GitHub and are not included in
`Aptitude-Lab-Setup.exe`. The installer contains only the example pair from the
repository's `templates` folder.

To add a question bank to an installed server, either upload a v2 ZIP directly
from Faculty → **Question banks**, or use the legacy folder workflow:

1. Download the desired archive or matching `.html` and `.json` files.
2. Extract the archive when necessary.
3. Copy both files, keeping the same base filename, into:

   ```text
   C:\ProgramData\Aptitude Lab\Question Banks
   ```

4. In Aptitude Lab, sign in as Faculty, open **Question banks**, select
   **Refresh folder**, and import the detected pair.

Keep correct answers and explanations in the JSON file only. The HTML file is
student-facing and should contain only the question text and visual content.

## Available downloads

- `ch01_number_system_complete.zip` - a textbook-verified Chapter 1 package
  built by the separate generalized data-engineering pipeline. It publishes
  312 readable questions with page, answer-key, numbered-solution, and derived
  difficulty lineage. It explicitly rejects 68 unresolved records instead of
  displaying flattened PDF formulas to students.

- `ch02_hcf_lcm_complete.zip` - a textbook-verified Chapter 2 package containing
  119 readable questions and 11 explicit layout rejections. Every answer is
  read from the textbook key, every solution is tied to its numbered source page, and legacy fraction notation,
  page continuations, empty solutions, and copied solutions are repaired through
  the chapter review ledger.

- `ch03_decimal_fractions_complete.zip` - a textbook-verified Chapter 3 package
  containing 90 readable questions and 116 explicit layout rejections. Its
  textbook answer key and numbered solutions are page-linked, and the review ledger repairs missing arithmetic,
  shifted records, cross-page spill, roots, fractions, and decimal notation.

- `ch04_simplification_complete.zip` - a textbook-verified Chapter 4 package
  containing 291 readable questions and 254 explicit layout rejections. It
  restores three source omissions, attaches shared directions and textbook solution setup to every dependent
  question, removes cross-question solution spill, and records a reviewed
  textbook-solution correction for the inconsistent printed key to question 545,
  and restores the continued-fraction questions 164-165 shown in the reported import defect.

- `ch36_tabulation_complete.zip` - a page-aware Chapter 36 package generated by
  the separate data-engineering pipeline. It contains all 60 verified source
  questions, including 20 reviewed cross-page associations, and includes
  explicit page/question/image lineage metadata for every crop and rejection.
  Its reviewed difficulty mix is 29 Easy, 27 Medium, and 4 Hard.

- `quantitative_aptitude_complete_extended.html` and
  `quantitative_aptitude_complete_extended.json` — the complete quantitative
  aptitude bank; copy both files together. Its 5,151 questions are categorized
  as Arithmetical Ability or Data Interpretation and assigned to 39 chapters.
  This is a legacy extraction and can contain flattened mathematical layouts;
  use the textbook-verified chapter ZIPs for student assessments. The source
  bank contains five-choice questions, including answers keyed to
  option E. Aptitude Lab supports both four-choice A–D and five-choice A–E banks.
- `quantitative_aptitude_categorized_v2.zip` — the same categorized questions in
  the smaller split-package format, including 45 shared Data Interpretation
  visual assets extracted from the supplied R. S. Aggarwal PDF. All 304 DI
  questions have an associated `stimulus_id`.
- `assessment-sample-30-questions.zip` — a downloadable copy of the sample bank
  included with the installer.
