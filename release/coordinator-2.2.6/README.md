# Superseded by Coordinator 2.2.7

Version 2.2.6 rejects valid runtime settings saved by 2.2.5 during installation.
Use [Coordinator 2.2.7](../coordinator-2.2.7/KSATCoordinatorSetup-2.2.7.exe)
and follow the [upgrade instructions](../../docs/coordinator-2.2.7.md).
Keep the existing ProgramData folder. The historical 2.2.6 binaries are retained
for traceability; do not use them for new upgrades.
